# STRUKTURA · бюджет внедрения

Отдел маркетинга и коммуникационная стратегия: бюджет по кварталам, KPI и три сценария.
Страница зашифрована AES-256-GCM, ключ выводится из пароля через PBKDF2-SHA256 (200 000 итераций).
Расшифровка в браузере, пароль никуда не отправляется. Пароль передаётся отдельно от ссылки.
